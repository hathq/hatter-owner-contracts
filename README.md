# Hatter owner contracts — 0.10.0

One exact owner reference, a CSPRNG incarnation, protocol generation and executable
digest form ProcessRef. PID and processkit restart count are not accepted identity
fields. Hatter orchestration issues incarnations; the physical adapter does not.

The 4 KiB handshake rejects unknown fields, stale generations, foreign owners/types,
mismatched protocol/executable and impossible dispatch availability. Observations
separate process life, transport, owner readiness and domain dispatch. No database,
Work, IPC framing or OS process code is present. Crowsi owns transport/framing and
pre-allocation limits. Owner wrappers can use this without linking processkit.

Initial restart classes are fixed policy declarations. Physical restart eligibility
never authorizes command replay or adoption of a semantic proposal.
